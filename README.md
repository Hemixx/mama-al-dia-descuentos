# Descuentos · Mamá al Día

Lista diaria de descuentos y beneficios vigentes para mamás, embarazadas y familias con niños pequeños en Chile (Santiago y regiones), que muestra la app **Mamá al Día** (https://mama-al-dia-31837.web.app).

- `deals.json`: la lista. La actualiza todos los días una rutina de Claude en la nube.
- `check-deals.mjs`: valida el formato y quita los vencidos (`node check-deals.mjs`).

La información se obtiene de páginas públicas; revisa siempre las condiciones en el sitio de cada tienda.
